    Samsung Health import

    Samsung Health has no public web API, so a website cannot pull from it directly. Export your data instead — Samsung Health → Settings → Personal data → Download personal data — unzip it, and drop the calorie or step CSV below. You will see a preview and can fix any number before it is saved.

    Sync across devices

    off

    Your log is saved in this browser and survives refreshing, closing the tab and going offline. Turn on sync to also keep it on the server, so the same log opens on your phone and your laptop — and survives clearing your browser data.

    There is no account. Pick a passphrase; it is stretched on this device and only the derived key is sent, so the server never sees it. Nobody can reset it — if you forget it, that data is gone. Use the same passphrase on your other device to pair them.

    Sync is on. Changes upload a moment after you make them, and this device pulls anything new whenever you return to the tab.
